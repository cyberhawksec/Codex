# Stackfall Web Version

A playable browser edition of Stackfall, the fruit-powered falling-block puzzle.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server.

## Controls

- Left / Right arrow: move
- Down arrow: soft drop
- Up arrow: rotate
- Space: hard drop
- Touch controls are available on mobile devices

The live game is available at https://stackfall-fruit-drop.shawnlim495280.chatgpt.site
