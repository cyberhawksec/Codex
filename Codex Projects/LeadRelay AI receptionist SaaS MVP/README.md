# LeadRelay AI receptionist SaaS MVP

Private, approval-first AI receptionist dashboard for local service businesses.

- Inbound call/chat lead capture and qualification
- Urgency detection, routing, and appointment booking workflow
- Personalized SMS/email drafts with human approval by default
- Consent-aware messaging, business-hours rules, and audit-oriented safeguards
- Lead status and conversion metrics
- Configurable placeholders for phone, calendar, CRM, and email integrations

Open `dist/index.html` in a browser to preview the static MVP.
